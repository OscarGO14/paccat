# clean-paccat

Removes repo noise from paccat without touching game source.
Driver: `.claude/skills/clean-paccat/clean.mjs`

## What it cleans

| Category | Pattern | Why noise |
|---|---|---|
| JS/TS duplicates | `src/**/*.js` with a `.ts` counterpart | TS is source of truth; Vite compiles at build time |
| Debug/verify scripts | `compare_mazes.js`, `debug.js`, `verify_*.js`, `test_*.js/mjs/html` | Created during dev sessions; not game features |
| Build artifact | `tsconfig.tsbuildinfo` | Regenerated by `tsc`; should not be committed |
| Worktree leftovers | `.claude/worktrees/` | Claude Code temp dirs; not project source |

## Run (agent path)

```bash
# Preview — no changes made
node .claude/skills/clean-paccat/clean.mjs

# Execute
node .claude/skills/clean-paccat/clean.mjs --apply
```

Output on apply (verified 2026-05-23):
```
21 items targeted, 0 skipped.
```

Also patches `.gitignore` to prevent these patterns from re-accumulating.

## After cleaning

Verify the game still builds:
```bash
npx tsc --noEmit
```

Expected: only pre-existing errors in `src/scenes/BootScene.ts:262-263` (null-check, unrelated to cleanup).

## Gotchas

- **Untracked files** (not in git) are deleted permanently — no `git restore`. Run dry-run first.
- The `.js` files in `src/` are **compiled artifacts** mistakenly committed, not hand-written. The `.ts` files are the real source.
- `tsconfig.tsbuildinfo` is regenerated by `tsc -b` (used by `npm run build`) — safe to delete.
- Pre-existing TS error in `BootScene.ts` exists before and after cleanup — not a regression.
