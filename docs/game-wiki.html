A Pac-Man-inspired browser game. Hungry cats, robot vacuums, mazes, and tuna cans.

Phaser 3 TypeScript Vite No external assets 3 levels
Overview
🐱
Player
Control a cat navigating tile-based mazes to collect fish and tuna cans.
🤖
Enemy
A robot vacuum chases you using BFS pathfinding. Activate power mode to flip the chase.
🐟
Objective
Eat every fish and tuna can on the board to clear the level and advance.
⚡
Power Mode
Collect a tuna can to scare the vacuum for 6 seconds — then eat it for bonus points.
❤️
Lives
Start with 3 lives. Touching the vacuum while not powered up loses one.
🎨
No Assets
All sprites are drawn procedurally via Canvas 2D at boot. Zero external images.

AI Behaviour

🔍 BFS Chase (hunting)

When not in power mode, the vacuum uses Breadth-First Search to find the shortest path to the cat on the tile grid. It returns the first direction of the optimal path and takes one step each frame.

bfsNextDirection(grid, fromX, fromY, toX, toY, forbidden) → Direction

The forbidden param prevents immediate reversal, keeping movement natural.

🏃 Manhattan Flee (scared)

During Power Mode the vacuum switches to a flee strategy: it evaluates all valid neighbours and picks the direction that maximises Manhattan distance from the player.

fleeDirection(grid, fromX, fromY, forbidden) → Direction

Fallback: if all flee directions are blocked, a random valid tile is chosen.

Decision Tree

scared? → flee (Manhattan max distance)
else → BFS to cat's tile
no path found? → random valid direction
can reverse? → never (forbidden direction enforced)
